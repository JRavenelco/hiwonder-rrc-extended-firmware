extension applied. It bundles the components below. None of them was modified by
this project except where the table says so; each keeps its own license, and the
license files that came with the vendor's package are kept next to the code.

everything outside `firmware/` were written for this project.

## What this project changed

Twelve files, all listed in [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md): eleven
of Hiwonder's (ten under `Hiwonder/` and the user section of
`Core/Src/stm32f4xx_it.c`) and `Hiwonder/USB_HOST/usbh_hiwonder_hid.c`, which
follows the structure of ST's USB host HID class driver. No file of FreeRTOS, LVGL, U8g2, Fusion,
SEGGER RTT, the Lw libraries, CMSIS or the HAL driver was touched.

## What was left out

The vendor package also contains Keil build outputs, CMSIS-DSP and CMSIS-NN, the
HAL sources of peripherals this firmware does not use, and the device headers of
the other STM32F4 microcontrollers. They are not part of the image and are not
included here.
